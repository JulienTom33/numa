# Internationalisation

- Référence : `docs/claude/development.md` (section Internationalisation).
- Un namespace par écran ou domaine ; partagé dans `common`, vocabulaire astrologique dans `astrology`.
- Clés en camelCase décrivant le rôle (`discover.start`), jamais le texte.
- Pluriels `_one` / `_other` ; en français 0 et 1 sont au singulier. Texte riche via `<Trans>`, jamais de concaténation de fragments.
- Nombres et dates via `src/i18n/format/format.ts`, jamais de format codé en dur.
- Toute clé ajoutée garde le typage strict vert (`npm run typecheck`).
